# BusinesSoar
BusinesSoar is an online interactive webapp that allows users to discover, rate, and review local businesses hidden within the community. 

# Features:
The interactive google maps banner displayed at the beginning of the webpage to provide direct access and information of local business and their locations. 
Below, there is a list of the businesses which can be sorted by categories, as well as ratings.
The option to create an account and add a business can be found on the top right corner of the webpage, where you need to sign in before having the ability to create a business or add reviews. 
BusinesSoar is available on pc, as well as phones!
Light and Dark Modes
In depth pages for each business 

# Tech Stack:
Uses java-script, HTML, CSS, and PostgreSQL

The front end of the webpage was built with a React framework with Next.js with the assistance of Vercel to host the main webpage. 
Front End:
Next.js (App Router) → frontend + server components 
Tailwind CSS → website styling 
React (client components) → interactivity 
Vercel → webapp deployment

Back End
Supabase (PostgreSQL) → database + backend services 
APIs:
Google Maps Platform → map window + location services + autocomplete
